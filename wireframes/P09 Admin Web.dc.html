Admin Web

Thirty-six screens, the largest single set on the estate and the one the client has never seen. Sixteen arrived as a name, a form template and one placeholder field — so most of the work here was deciding what a screen called "management" is actually for.

Twelve screens are one form

ADM-008, 011, 014, 015, 017, 019, 021, 024, 025, 026, 030 and 032 — plus SUP-003 on the support console — are all a scoped settings form with a save, an audit entry and an inheritance indicator. Build the template once.

ADR-0018 is the reason

A value must say whether it is the venue’s own, the region’s or the tenant’s. Without it a manager changes a setting, nothing happens, and they conclude the system is broken.

Five screens are one pipeline

ADM-022 to ADM-026 are draft → staged → promoted → notified → end of support. That is the client’s own Publishing Status stepper, not a fifth pattern.

Flow map

Six clusters. An operator works inside one of them per session and rarely crosses.
