# TICVAI frontend

Nx workspace: the package's 13 apps and four shared packages.

## Run it

Requires Node 22 and pnpm 9 or newer.

```
pnpm install
pnpm lint
pnpm typecheck
pnpm test
```

## Working with Claude Code

`CLAUDE.md` tells Claude how this workspace is laid out and how to work a ticket through ADAM.
The team's coding standards are in `project-bible/setup/`.
