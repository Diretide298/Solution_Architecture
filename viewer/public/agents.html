Overview

Claude Code runs on each developer’s machine, so this is what their hooks have sent: which tools ran, whether they worked, how long they took, and which ticket was open. Never the prompts, the arguments or the code — so this can say that Edit failed eleven times on a ticket and not what it was trying to edit.

Nothing has arrived yet. The hooks are installed per machine — see viewer/mcp/hooks/README.md — and a session is sent when it ends, not while it runs.

Who is using it

Active time, not wall clock: a session left open over lunch is not an hour of agent use, so gaps longer than five minutes are not counted.

Tools and failures

Sorted by what is failing rather than by what is used most. The error words are classified on the machine — the messages themselves are never sent, because they carry paths and snippets.
