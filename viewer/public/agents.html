People

Active time, not wall clock: a session left open over lunch is not an hour of agent use, so a gap longer than five minutes between two events is not counted. A name opens that person on Tasks.

Tools failing

Every tool the agent called, the ones failing most first. Why a call failed is classified on the machine into one of six words (not-found, refused, timeout, conflict, cancelled, error); the message itself is never sent, because it carries paths and snippets of code.
