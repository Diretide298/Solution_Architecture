What this rests on

    Per person

    Logged hours against the rate set for that name. Somebody with hours and no rate shows a dash rather than a zero, because a zero reads as free. A rate marked at the default is the project's stand-in, not what that person costs.

    Per sprint

    Per week

    Budget

    What the project was given to spend. A change is kept beside the one it replaced, with who made it and when, because a budget that moved without a trace makes every "over by" on this page meaningless.

    The budget is set by an administrator. You can read it and its history.

    Every budget this project has had

    Rates

    Set against the name OpenProject uses, because that is what the hours arrive attached to. Pick from the list: a rate typed against a name the tickets do not use matches nothing.

    Rates are set by an administrator. You can read them.

    Default rate

    Optional. Used for anybody with logged hours and no rate of their own, and every amount it produces is marked at the default, so it is never mistaken for what that person costs.

    What is missing

    Counted rather than absorbed. Each of these makes the spend an understatement or the projection a guess, and each is fixed by somebody different.
