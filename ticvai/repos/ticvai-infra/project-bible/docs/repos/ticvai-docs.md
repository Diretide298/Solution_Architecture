# ticvai-docs

The documentation repository. The folders it shares with the package (`contracts`, `states`, `flows`, `events`,
`screens`, `docs`, `frontend`, `tools`, `handoff`, `sources`, `diagrams`) are copies of the package, written by
`tools/derive-mirrors.py`: never edit them here. The other folders hold the setup standards and older documentation.

## Start here

- [setup/quickstart.md](setup/quickstart.md), then the setup standards indexed in [setup/README.md](setup/README.md).
- [overview.md](overview.md), [glossary.md](glossary.md) and [gotchas.md](gotchas.md).
- [docs/active/README.md](docs/active/README.md): what is in flight now.
- [repos/README.md](repos/README.md): the rules specific to each repository.
