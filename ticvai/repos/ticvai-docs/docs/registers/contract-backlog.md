## Why an edit is deferred rather than made

The test is applied, not judged: **does this edit touch only the contract being walked, and does that contract already contain a precedent for how it should look?** Both yes is settled. Anything else is deferred.

It was written as a test because judgement got it wrong the first time it was used. **BL-002 — the missing footer — looks like an obvious mirror of the header** until you notice a header is chrome and a footer is a link surface pointing at policy records the CMS may already compose. Instinct said build it; the test said wait.
