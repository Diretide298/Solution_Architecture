Hard duplicates

Screens that are not merely similar. Each group below shares a name, a purpose or an exact operation set with another screen, and no difference in the definitions explains why both exist. These need a decision — keep one, or write down what makes the second one different.

EMP-010Scan — ready EMP-015Group scan SCN-007Group admission SCN-008Manual entry SCN-009Ticket lookup SCN-013Offline journal SCN-015Offline package BO-034Scan Activity

Read this one carefully. The signature is identical because the operation list was applied wholesale to a whole platform, not because all eight screens do the same job — a gate admission and an offline package status are different screens. The real redundancy is the pairing across P06 and P07: EMP-010 ≡ SCN-007, EMP-015 ≡ SCN-008 and EMP-017 ≡ SCN-014 (a separate nine-operation sync signature). The fix is to say which app owns scanning, not to merge the seven operations.
